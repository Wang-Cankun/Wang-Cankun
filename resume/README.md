# Resume development

Edit `cankun-cv.json` for content and `cankun-cv.template.html` for layout. Fonts and their licenses are bundled in `fonts/`.

With [uv](https://docs.astral.sh/uv/) and Google Chrome installed, run from the repository root:

```sh
uv run resume/build.py
```

The script installs its pinned Python dependencies through uv, then renders locally using Chrome. It generates `resume/cankun-cv.html` and the root `Cankun_Wang_CV.pdf`, preserving the profile CV link. Open the HTML for preview and inspect the PDF after rebuilding. Commit the source, fonts, HTML, and PDF together.

This repository maintains the public CV. Keep employment records and application material in the private career workspace. The root DOCX is a legacy version and is not generated by this build.
